智慧树 · 一键全自动　使用说明
======================================================================

一、这是什么
本程序有两个入口：
  · 「智慧树课程助手.exe」：图形界面，扫描课程目录、查看完成状态、选课节播放（见第二节）
  · 「一键开始.exe」：命令行全自动模式，作业 + 看课一次跑完（见第四节）

双击「一键开始.exe」后，程序会自动：
  1. 打开浏览器（独立配置，不影响你平时用的浏览器）
     优先用 Edge / Chrome 等 Chromium 系；没装则自动改用 Firefox
  2. 等你登录智慧树（扫码或账号密码都行）
  3. 找出所有「未提交」的作业，逐题作答并提交
  4. 自动播放课程视频（1.5 倍速、自动处理弹题、自动切下一节）
  5. 结束后停在窗口里，显示本次结果

二、图形界面：智慧树课程助手（推荐）
双击「智慧树课程助手.exe」，是一个独立的桌面窗口，不需要命令行：
  1. 点右上角「刷新目录」：打开浏览器扫码 / 账号登录后，自动扫描所有课程的
     章节和课节，连每节视频时长、是否已完成一起读出来
  2. 左侧选课程，右侧看章节 → 课节；✓ 表示已完成，○ 表示未完成
  3. 选中一节，点右下角「开始完成这节」，程序会自动播放并完成这节课
  4. 底部「运行日志」实时显示每一步；运行中可以点「停止」中断
  目录数据保存在 app\export\course-catalog.json，下次打开直接读取，无需重扫。

三、适用网站（程序实际访问的页面）
  本程序只针对「智慧树」学生端（zhihuishu.com），不访问其它平台：
  1. 登录中心     https://login.zhihuishu.com/
  2. 学生首页     https://onlineweb.zhihuishu.com/onlinestuh5
  3. 视频学习页   https://studyvideoh5.zhihuishu.com/stuStudy?recruitAndCourseId=...
  4. 作业列表     https://onlineexamh5new.zhihuishu.com/stuExamWeb.html#/webExamList?recruitId=...
  5. 作业作答     https://onlineexamh5new.zhihuishu.com/stuExamWeb.html#/webExamList/dohomework/...
  6. 作业复习     https://onlineexamh5new.zhihuishu.com/stuExamWeb.html#/webExamList/checkHomework/...
  数据接口：onlineservice-api.zhihuishu.com、studyservice-api.zhihuishu.com
            （只在已登录的浏览器页面里读取课程 / 作业数据）
  提示：平台改版可能导致域名或页面结构变化，届时程序需要同步更新。

四、第一次使用
  1. 双击「一键开始.exe」。
  2. 浏览器打开后，登录你的智慧树账号。
  3. 登录成功后不用关浏览器，程序会自动继续。
  4. 首次运行会先抓取你自己的课程 / 作业数据，可能多等几分钟。
  5. 结束后看窗口汇总；有未完成项就按提示处理后，再双击一次。
     已经完成的作业和课节会自动跳过，不会重复做。

五、环境要求
  · Windows 10 / 11（64 位）
  · 以下浏览器任选其一（推荐 Edge，Windows 自带即可）：
      Microsoft Edge / Google Chrome / Firefox
    程序会在运行时检测这台电脑实际装了哪些浏览器，装了哪个就用哪个；
    同时装了多个时优先用 Chromium 系，只有 Firefox 时会自动走 Firefox
  · 安装包已自带 Node 运行时，不需要另装 Node.js

六、AI 兜底（可选，不配置也能跑）
随包附带一份题库，能覆盖常见题目。
题库里没有的题：程序会先尝试 AI；没有配置密钥时随机选一个，保证整份作业能正常提交。
想提高正确率再配置：
  1. 双击「设置AI密钥.exe」
  2. 在弹窗里粘贴 DeepSeek API Key，点「保存」
     （API 地址、模型也可以在同一个窗口里改）
  3. 重新运行「一键开始.exe」

  答错自动复盘（默认开启）：
  作业提交出分后，程序会自动打开复习页核对错题，重新思考答案，
  并把修正后的答案存进 app\export\answer-overrides.json（下次同类题优先使用）。
  如果平台还允许重做，会尝试自动申请重做并再答一轮（默认最多 2 轮）。
  不想复盘可在命令行加 --no-rethink；只想复盘不想重做可加 --no-redo。

七、数据放在哪
  安装版：C:\Users\你的用户名\AppData\Local\智慧树一键全自动\
  便携版：解压出来的文件夹里
    app\export\                 抓取到的课程与作业数据
                                （answer-overrides.json 为错题复盘后沉淀的答案）
    app\recon\apply\            每次运行的报告
                                （auto-answer-report.json / watch-report.json）
    app\browser-profile-*\     登录态，只保存在本机
                                （用哪个浏览器就生成哪个目录，换浏览器会各存一份）

八、常见问题
  · 一直提示等待登录：在浏览器里完成登录即可；超过 15 分钟会退出，重开一次就行。
  · 只装了 Firefox：不用改任何设置，程序会自动用 Firefox 接管；
    若想强制指定浏览器，可在命令行加 --browser firefox 或 --browser-exe 浏览器路径。
  · 平台要求人脸识别：不用管，也不要点关闭。程序会自动等你完成，完成后继续播放；
    超过 15 分钟没完成才会停下（可在命令行加 --face-wait 分钟数调整）。
  · 作业会全部自动提交：个别题题库和 AI 都答不出时会随机选一个，不会因为一两题卡住整份作业。
  · 仍然停下时：基本只剩平台硬限制（学习时间已达上限、异常脚本风控），
    这类无法自动绕过。稍后重新双击一次即可，已完成的作业和课节会自动跳过。
  · 提示「未知发布者」：程序未购买商业代码签名证书，
    点「更多信息 → 仍要运行」即可。
  · 卸载：Windows 设置 → 应用 → 智慧树一键全自动 → 卸载。

九、使用边界
本程序只是把重复操作自动化，请遵守学校与平台的使用规定，仅用于自己的账号。
